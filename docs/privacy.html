Privacy Policy for SipSmartAI

Last updated: December 2025

SipSmartAI is a university project developed for educational purposes. This app helps users track drinks, view drink details, and scan product barcodes. This Privacy Policy explains how the app handles data and user information.

Information We Collect

1. Camera Access

SipSmartAI uses your device’s camera only for scanning barcodes to retrieve drink information.

  • We do not record, store, or transmit any camera images.
  • No biometric or personal data is collected through camera usage.

2. User-Provided Data

If the app allows login or storing drink selections, this information is only used within the app to provide functionality.

  • No personal data is sold or shared.
  • All data stays in the Firebase project linked to this app.

3. Automatically Collected Data

SipSmartAI may collect basic analytics such as:

  • Device type
  • App usage (screen views, interactions)

These are used only to improve functionality and app stability.

How We Use the Information

The data SipSmartAI accesses or stores is used to:

  • Provide core app features (barcode scanning, drink tracking)
  • Improve user experience
  • Maintain basic analytics for educational purposes

We do not:

  • Sell user data
  • Share data with third parties
  • Use data for advertising

Data Security

We store any necessary data using Firebase services. Access to this data is restricted to authorized team members working on the project.

Children's Privacy

SipSmartAI is not directed toward children under 13. We do not knowingly collect personal information from children.

Changes to This Policy

We may update this Privacy Policy as part of our academic project. Updates will be posted in this GitHub repository.
